# AI 데이터 처리 확인 메모

확인일: 2026-09-30

운영 준비를 위한 내부 메모다. 고객에게 적용되는 약관·법적 안내를 확정하는 문서가 아니다. 소스 코드와 Google 공식 문서를 확인했으며, `.env`, API 키, 실제 Google 프로젝트의 결제·데이터 공유 설정은 열람하거나 검증하지 않았다.

## 현재 코드에서 확인한 처리

- `backend/app/yeoul.py`의 `context_for()`는 별명, 관심 주제, 직접 작성한 질문, 관계 상태, 출생 시간 미상 여부, 해석 기준일과 계산된 사주 자료를 Gemini에 전달한다. 원래 생년월일·출생 시각을 별도 필드로 재전송하지 않지만, 계산된 사주 자료와 질문도 개인에 관한 정보를 포함할 수 있다.
- `request_json()`은 Gemini Interactions API에 `store: false`로 요청한다. `answer_followup()`은 새 질문과 함께 기존 풀이 전체 장 및 최근 추가 질문 대화 최대 2개를 보낸다.
- `backend/app/main.py`는 요청 시점부터 24시간이 지난 작업을 만료시키며, 결과와 입력은 서버 메모리에 있다. 주기적 정리는 60초 간격이고, 조회·삭제 등 요청 시에도 만료를 확인한다. 서버 재시작 시 더 일찍 사라진다.
- `DELETE /api/v1/tasks/{task_id}`는 조회 권한을 확인한 뒤 여울 서버의 작업·결과를 제거하고 진행 중 생성을 취소한다. Google의 자료를 삭제하는 API 호출은 없다. 선택한 브라우저 보관은 30일이며, 내려받은 파일은 이용자가 별도로 관리한다.
- `backend/app/yeoul_routes.py`의 `GEMINI_PAID_SERVICE_CONFIRMED`는 운영자가 지정하는 확인 플래그다. Google Billing 또는 데이터 공유 설정을 자동 검증하지 않는다. 현재 개인 풀이 생성은 별도의 개발용 허용 조건에 제한되며, 실제 판매와 구매 결과 전달은 비활성화되어 있다.

## 공식 정책과 구분할 점

- **유료 적용 조건:** Gemini API는 호출에 쓰는 Cloud Project에 활성 Cloud Billing 계정이 연결되어 있어야 Paid Services로 분류된다. 유료 서비스의 기본 정책은 입력·출력을 Google 제품 개선에 사용하지 않는 것이다. 무료 서비스에는 개인·민감·기밀정보를 제출하지 말라는 제한이 있다. [Gemini API 약관](https://ai.google.dev/gemini-api/terms)
- **보안 목적 보관:** Google의 부정 이용 감시 문서는 입력·문맥·출력을 55일 보관한다고 설명한다. 이상 징후가 있는 자료는 권한 있는 직원이 검토할 수 있다. 이 자료는 정책 집행용 모델을 제외한 AI/ML 모델 학습·미세 조정에 사용되지 않는다고 안내한다. [Abuse monitoring](https://ai.google.dev/gemini-api/docs/usage-policies)
- **`store: false`의 범위:** 일반 대화 상태 저장을 끄는 설정이며, 부정 이용 감시 목적 보관까지 없앤다는 뜻이 아니다. ‘Google에 전혀 저장되지 않음’으로 설명하지 않는다. [Zero data retention 안내](https://ai.google.dev/gemini-api/docs/zdr)
- **별도 데이터 공유:** 유료 프로젝트라도 운영자가 로그 데이터셋이나 피드백을 Google에 공유하면 해당 자료는 제품 개선·모델 학습·사람의 검토에 사용될 수 있다. 여울이 이 기능을 사용한다고 확인된 것은 아니다. [Data logging and sharing](https://ai.google.dev/gemini-api/docs/logs-policy)

## 출시 전 확인 목록

- [ ] 실제 운영 API 키가 속한 **호출 프로젝트**와 활성 Billing 연결을 확인한다. 플래그 설정만으로 확인을 대신하지 않는다.
- [ ] 운영 프로젝트의 로그·데이터셋·피드백 공유 설정과 운영 절차를 확인한다. 이용자 자료를 제품 개선용으로 공유하지 않는 기준을 정한다.
- [ ] 초기 풀이와 추가 질문 등 운영 요청에서 `store: false`가 유지되는지 검증한다.
- [ ] Google의 보안 목적 **55일 보관**과 필요한 경우의 담당자 검토를 여울 자체 보관 기간과 구분해 안내한다. 출시 시 공식 정책을 다시 확인한다.
- [ ] 여울의 삭제가 Google의 보안 목적 자료 또는 이용자가 내려받은 파일의 즉시 삭제를 뜻하지 않는다는 점을 안내한다.
- [ ] 실제 운영 보관·삭제·전송 범위를 확인한 뒤 결제 직전 요약과 상세 개인정보 안내를 일치시킨다. 확인 전에는 ‘학습에 절대 사용하지 않음’, ‘완전 무보관’, ‘모든 사본 즉시 삭제’를 약속하지 않는다.

현재 계정에 위 조건이 적용되는지는 **미확인**이다. 이 메모 작성은 출시 조건 충족 확인이나 실제 판매 활성화를 의미하지 않는다.
